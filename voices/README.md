# voices/

Pip voice-line audio clips (ElevenLabs recordings). Drop `.mp3`/`.ogg`/`.wav`/`.m4a`
files here directly — either with git, or via GitHub's own "Add file → Upload files"
button, typing `voices/yourfile.mp3` as the destination path.

Files here show up automatically in the app's Parent Zone → Settings → Voice Lines
tab (via GitHub's Contents API) — no code change needed to use a new one, just pair
it with its text and moment in that tab after uploading.
